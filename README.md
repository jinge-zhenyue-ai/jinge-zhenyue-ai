# 金戈枕月 AI Agent

> 一个**本地运行、隐私优先**的「桌面 AI 助手」。以**单个 exe 文件**分发，Windows 上**双击即用**——无需安装 Python、无需配置开发环境。它在本机起一个仅自己可访问的服务，并用 Microsoft Edge 的 `--app` 模式包装成**无地址栏的独立桌面窗口**。
>
> 内置长期记忆（用户档案）、实时对话历史、审计日志与防篡改哈希链、自主健康自检与修复、性能加速层、3D 粒子发送按钮、待完成任务队列、天气 / 应用唤起 / 文件生成 / 社群等功能；可对接**本地 Ollama** 或**云端大模型 / 语音 API**。

> **版本**：本文档对应本次发行版 **v108**（exe 构建版）。

---

## 一、这是什么

「金戈枕月」是**个人本地 AI 助手**，不是云端 SaaS，也不是付费产品。它的核心立场是：

- **数据不出本机**：默认、推荐使用本机 Ollama 模型，完全离线、零成本、隐私可自主掌控。
- **单文件便携**：只有一个 `金戈枕月.exe`，下载即用，删掉即卸载，不污染系统。
- **本地服务**：后台绑定 `127.0.0.1:8765`，只对本机开放，外部网络无法访问。
- **桌面体验**：用 Edge `--app` 模式呈现为无地址栏窗口，启动自动打开。

> 本项目为**闭源发行**（仅提供编译后的 exe）。本文档面向使用者，讲清下载、安装、使用、配置与安全机制。

## 二、配置要求

为了让 3D 粒子按钮流畅渲染、语音与多任务顺畅，建议满足下表；**达不到也能运行**，只是部分视觉 / 性能特性打折。

| 项目 | 推荐配置 | 说明 |
|------|----------|------|
| **操作系统** | Windows 10 / 11（64 位） | 桌面窗口依赖 Microsoft Edge |
| **Microsoft Edge** | 已安装（Win10/11 通常自带） | 承载桌面窗口；未装请先安装 Edge |
| **WebView2 Runtime（必备）** | 已安装（Win10/11 通常自带；缺省可在微软官网下载安装） | **电脑必须有的环境**，承载桌面窗口渲染内核；未安装会导致窗口无法正常显示 |
| **显示器** | 27 英寸及以上 | 全屏窗口运行，大屏信息展示更完整 |
| **显卡** | NVIDIA RTX 3050 及以上 | 3D 粒子点云依赖 GPU；低于此退化为普通圆形按钮（功能不受影响） |
| **CPU** | Intel Core i5-12400F 及以上 | 本地模型推理 / 任务调度 / 语音基线 |
| **内存** | 16 GB 及以上（建议） | 本地模型与浏览器内核同机运行 |
| **硬盘** | 需有剩余空间（日志会轮转，见第九节） | 用户档案与日志默认写 `D:\金戈枕月用户档案\` |
| **联网** | 按功能需要 | 天气、3D 点云（CDN 加载 Three.js）、云端模型需联网；本地 Ollama 对话可离线 |

> ⚠️ 三项重点体验门槛：**27 寸以上显示器、RTX 3050 以上显卡、i5-12400F 以上 CPU**。

## 四、数据存放位置（务必注意）

所有个人数据默认存放在 **D 盘固定目录**（刻意避开 C 盘，降低权限与清理风险）：

```
D:\金戈枕月用户档案\
├── profile.md            # 用户长期记忆（关于"用户这个人"的画像）
├── history\              # 历史对话归档（每条对话一个文件）
└── 软件日志\              # 程序运行日志（分日滚动，支持轮转压缩）
    ├── YYYY-MM-DD.log    # 当日日志（含全部级别：DEBUG/INFO/WARN/ERROR）
    └── log_archive_index.json  # 归档清单（记录被压缩旧日志的 sha256 校验）
```

- AI 生成文件：当前用户目录下的 `金戈枕月输出\`（运行时自动创建）。
- 社群二维码：程序内置。

> ⚠️ **无 D 盘自动回退**：没有 D 盘时自动写到当前用户目录，不会启动失败。
> 💡 浏览器端另有一份 `localStorage` 缓存兜底；**以磁盘存档为准**。

## 八、安全 · 日志 · 审计机制（本次重点）

面向长期 7×24 运行与数据安全，本项目内置一套**防篡改、防爆盘、抗崩溃**的日志与审计体系。

### 1. 日志完整分级与优先级面板

- 后端 `append_log(level, module, msg)` 按级别落盘；前端面板**支持按 DEBUG / INFO / WARN / ERROR 筛选**。
- 修复要点：旧版面板只读**内存缓冲**，早期 DEBUG / ERROR 被海量日志挤出后查不到；现在**以磁盘文件为权威来源**，所有级别（含 DEBUG / ERROR）都能稳定查到。

### 2. 日志轮转与压缩归档（防爆盘）

| 策略 | 值 | 说明 |
|------|----|----|
| 单文件触发归档 | **> 1000 MB** | 超限自动 gzip 压缩归档 |
| 时限触发归档 | **超过 2 天** | 旧的日日志自动压缩 |
| 归档保留期 | **30 天** | 过期压缩包自动删除 |
| 归档校验 | **SHA-256** | 压缩时计算原文件 sha256，写入 `log_archive_index.json`，可复核完整性 |
| 执行方式 | 启动时一次 + 后台每 6 小时一次 | 长期运行不撑爆硬盘 |

### 3. 审计日志 · 防篡改哈希链

- 审计系统记录全部用户操作与关键 API 调用，每一条都带 **SHA-256 哈希链**：
  `hash_i = SHA256(前一条哈希 + 本条内容)` —— 任何一行被改 / 删 / 插入，链条即断，并能定位到行号。
- **按文件独立哈希链**：不再维护单条横跨所有历史的连续链，而是**每个日志文件（每日、或单文件超限后的分片）各自从 genesis 独立起链**。结论：即使程序闪退、被强制结束、断电，顶多**当前这一份文件**的链断掉，**不会污染之前全部历史日志**。
- 近期校验建议（可选）：崩溃 / 断电后可用内置诊断能力复核审计链，所有历史文件可独立验证。

### 4. 系统诊断与自主修复

- **系统诊断面板**：一键检查损坏消息、LLM 配置、Ollama 连接、localStorage 健康、后端 API 状态、历史索引完整性、磁盘空间等，前端每 5 分钟 + 手动触发。
- **自主修复**：检测到损坏消息 / 无效 LLM 配置 / 配置缺失时自动修复（如修正 temperature、切回存在的模型、重建缺失配置），并把操作记入日志。

### 5. 性能加速层（零侵入）

- **gzip 压缩**：大响应自动压缩（>500B，压缩率 40–80%）。
- **GET 缓存**：白名单路径 30s TTL；静态 JS/CSS 缓存 1 小时。
- **请求合并**：拦截相同 pending 请求，复用结果。
- **日志批处理**：2s 定时批量落盘，降低 I/O。

## 十、使用注意事项（必读）

1. **只在本地运行**：服务绑定 `127.0.0.1`，请勿端口映射 / 反向代理到公网。
2. **数据盘**：默认 `D:\金戈枕月用户档案`，无 D 盘自动回退用户目录，请勿误删。
3. **未安装的应用无法唤起**：「打开应用」依赖本机已安装且有开始菜单快捷方式。
4. **本地 LLM 连不上**：通常是 Ollama 未启动或模型未拉取；启动 Ollama 并 `ollama pull qwen3:4b` 后重试。
5. **API Key 安全**：Key 在浏览器 `localStorage`，勿在公共电脑保存。
6. **未成年人合规**：调用国内云平台 API 前请完成实名认证；未实名被风控拦截属正常。
7. **3D 点云需联网**：离线时按钮退化为普通圆形按钮，功能不受影响。
8. **历史双重存储**：磁盘 + `localStorage`，以磁盘为准；删除磁盘文件即永久丢失。
9. **日志自动轮转**：日志超过 1000MB 或 2 天自动压缩归档、30 天后清理，无需手动维护；如需清空需在界面手动确认。

## 十一、故障排查

| 现象 | 可能原因 | 解决办法 |
|------|----------|----------|
| 启动无窗口 / 一闪而过 | Edge 未装 / 被杀软拦截 | 装 Edge；允许运行；查看软件日志 |
| 界面白屏 / 旧样式 | Edge 缓存 | 重开 exe；或 `Ctrl+Shift+R` 强刷 |
| 发送按钮无 3D 点云 | 离线 / CDN 被墙 / 显卡过低 | 联网强刷；或接受退化按钮 |
| 面板选 DEBUG/ERROR 查不到 | 旧版读内存缓冲导致丢失 | **已升级 v108**（改从磁盘读，全级别可查） |
| 云端 API 返回 404 / 403 | 账号未实名 / Key 无效 | 完成实名认证、核对 Key；非程序问题 |
| 语音无声音 | 麦克风未授权 / 无中文神经语音 | 授权麦克风；安装微软中文神经语音 |
| 历史不显示 | 磁盘目录损坏 / 权限不足 | 检查 `history\` 是否可写 |
| 审计链告警（断电 / 强杀后） | 当前文件哈希链断裂 | 仅该文件受影响，其余历史独立完好；可导出诊断 |
